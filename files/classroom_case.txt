AI 활용 잡크래프팅 · 기업 실습용 사례
===================================
[구분] 교육용 가상 예제. 실제 고객·기관 성과와 무관.

1. 상황
인사교육 담당자가 신규 입사자 교육 안내문을 제작한다. 일정과 장소, 준비물, 신청 마감이 종종 빠져 담당자의 재수정을 요청받는다.

2. 실습에 사용할 확인된 원자료
- 교육명: 신규 입사자 온보딩
- 일시: 2026년 12월 3일(목) 14:00~16:00
- 장소: 본사 3층 교육실
- 대상: 2026년 11월 입사자
- 준비물: 노트북, 사원증
- 신청 방법: 사내 포털, 2026년 11월 27일까지
- 담당자 이메일/신청 URL: 미확인 (임의로 만들어서는 안 됨)

3. 기존 방식
담당자 요청 메일 → 자유 형식 초안 → 검토 → 빠진 정보 확인 → 수정 → 발송

4. 개선 방식
필수 정보 입력 양식 → AI 초안 보조 → 원자료 대조 → 인간 승인 → 발송

5. 실습용 프롬프트
아래 제공된 사실만 사용하여 신규 입사자 교육 안내문을 작성해 주세요.
일시·장소·대상·준비물·신청방법을 모두 포함하고,
제공되지 않은 연락처·URL은 추측하지 말고 [확인 필요]로 표시하세요.
제목/안내 본문/담당자 검수 목록 순서로 작성하세요.
최종 발송 여부는 사람이 결정합니다.

6. 검수 기준
[ ] 행사명/일시/장소가 원자료와 정확히 일치
[ ] 대상/준비물/신청마감/신청방법 누락 없음
[ ] 미제공 연락처나 URL을 임의 생성하지 않음
[ ] 최종 승인자 확인 완료
[ ] 동료 검토시간과 재작업 부담 증가 여부 확인

7. 계산 연습 (모두 가상 수치)
기존 80분/건, 개선 55분/건(준비·작성·검수·수정 포함), 최초 설정 120분,
주 4건 반복, 추가 유지보수 0분, 동료 검토시간 변화 없음이라고 가정하면
건당 25분, 주 100분 순절감, 최초 설정시간 회수 예상 약 1.2주.
품질에 문제가 생기면 개선이라고 판정하지 않는다.

8. 실제 파일럿에 필요한 추가 자료
날짜별 작업 원본 / 기존·개선 기준 작업 기록 / 실제 오류·수정 로그 /
동료 확인 / 기관의 개인정보·보안 정책 / 유지보수시간.
