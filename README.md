# 꿈쓰는회사 × 권글 | 잡크래프팅 V9 · 교육 운영/성과 관리

## 전체 사이트 페이지
메인 페이지에 V9 학습 운영 동선(실습 → 결과 제출 → 강사 대시보드)을 추가했습니다. 모바일에서는 기존 상단 메뉴가 숨겨질 수 있으므로 메인 본문에서도 각 신규 페이지에 접속할 수 있습니다.

- `index.html`: V8 통합 홈페이지
- `curriculum.html`: 2/4/8/16시간 강의계획안
- `practice.html`: 10개 인터랙티브 실습 (V8 기능 유지)
- `checkin.html`: V9 **교육 전/직후/7일/14일 익명 진단·결과 제출**
- `dashboard.html`: V9 **강사용 CSV·JSON 가져오기, 사전-사후/현업 실행/실측 비교, 인쇄 보고서**
- `proposal.html`: 기관 맞춤 제안서
- `research.html`: 연구 근거와 한계
- `assets/`: 스타일/JS 및 기존 PDF·워드 자료

## Netlify 배포
1. ZIP을 **압축 해제하지 않고** Netlify 사이트 > Deploys(배포)에서 수동 업로드합니다.
2. 사이트 설정에서 Netlify Forms의 form detection(양식 감지)이 활성화되어 있는지 확인합니다.
3. 배포 후 `https://YOUR-SITE.netlify.app/checkin.html`로 접속하고 1건의 비실명·비기밀 테스트 응답을 전송합니다.
4. Netlify 사이트 > Forms > `jobcraft-v9-submissions` 에 제출 기록이 있는지 확인하고 필요하면 Spam도 확인합니다.
5. Forms에서 CSV 내보내기를 실행한 뒤 `dashboard.html`에서 가져오면 집계됩니다.
6. HTTPS 사용자 지정 도메인에서도 제출할 수 있으며, `file://` 로컬에서는 서버 제출이 불가능합니다. 로컬에서는 JSON 백업으로 사용합니다.

## 강사 참여 링크 만들기
`dashboard.html` 상단의 교육 코드·교육시간·대상을 선택하면 교육 전/직후/7일/14일 참여 링크가 각각 생성됩니다. 링크는 Netlify 배포 사이트의 주소를 기준으로 생성되며, 로컬 파일을 열었을 때는 `file://` 형태이므로 실제 배포 주소에서 만들어 공유하세요.

## 강의 현장 안내
- 강사가 `TEAM-2026-11`처럼 교육 코드를 정해 참가자에게 배포합니다(4~24자리 영문/숫자/-/_).
- 참가자는 동일한 참가자 코드를 교육 전·후·7일·14일에 사용합니다. 이름/이메일은 수집하지 않습니다.
- 참가자 실습(`practice.html`) 기록은 **기본적으로 브라우저 내부**에 머무르고 **자동으로 제출되지 않습니다**. 참가자가 `checkin.html`에서 동의하고 전송한 요약 지표만 Forms에 제출됩니다.
- 강사 대시보드에는 로그인, 비밀번호 보호, 자동 서버 데이터 조회 기능이 **없습니다**. 페이지를 열어도 응답이 보이지 않으며, 강사가 관리자 권한으로 CSV를 내려받아 자신의 브라우저에 불러와야 합니다.
- 데이터가 포함된 파일은 브라우저 메모리에서만 처리하고 새로 고침 시 사라집니다. 가져온 파일 자체는 강사가 보안 규정에 맞게 관리해야 합니다.

## 집계 규칙
- 고유 참가자: 교육 코드 + 참가자 코드.
- 중복 시점 제출: 해당 코드·시점에서 `submitted_at` 기준 최신 건 우선.
- 사전·사후: 두 시점이 모두 있는 **짝지어진 응답**만 5개 문항별 비교.
- 7·14일: 추적 시점 응답률을 표시하되 미응답을 실패로 간주하지 않습니다.
- 생산성: **동일 기준 실측(`measured`) + 품질 충족(`pass`) + 시간 두 값이 모두 기입**된 응답만, 참가자별 최신 유효건 1건으로 집계.
- 5개 문항은 교육 목적의 자체 문항입니다. 검증된 심리 측정, 인과적 교육 효과를 주장하지 않습니다.
- 시각화의 `가상 예시 보기`는 명시적인 모의 데이터로 표시됩니다.

## 보안/개인정보
- 교육 코드와 참가자 코드는 익명에 가까운 **가명 식별자**이지 완전한 익명성을 보장하지 않습니다. 코드와 사람이 대응되는 명단을 별도 보관하면 개인정보에 해당할 수 있습니다.
- 기업 비밀정보·개인정보를 입력하지 않도록 참가자에게 안내하세요.
- Netlify Forms 데이터는 사이트 운영 계정에 보관되므로 운영자가 수집 고지/보관 기간/삭제 책임을 정해야 합니다.
- CSV와 JSON은 분석 목적으로만 불러오고 클라이언트 브라우저에서 처리합니다. 대시보드를 외부 공개해도 CSV 파일 자체가 자동 공개되지 않지만 **관리자 인증/권한 관리 시스템은 아닙니다**.
- 수신에 실패한 경우에는 성공 메시지를 표시하지 않습니다.

## 기능 점검 시 주의
Netlify Forms는 **정적 HTML 양식 감지** 방식이므로 새 폼은 Netlify에 실제 배포된 뒤에 등록됩니다. 일반 로컬 서버의 POST는 폼으로 저장되지 않습니다.
