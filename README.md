## 배포
`index.html` 이 ZIP 최상위에 있도록 이 패키지 전체를 Netlify Deploys에 업로드합니다.
본 ZIP은 정적 사이트만 포함합니다. 회원가입·계정·외부 API 키·DB 연결이 필요하지 않습니다.

## 개인정보와 실제 운영 확인
- 실습 카드·계산기는 브라우저에서만 작동하며 서버로 전송하지 않습니다.
- 다운로드한 TXT 파일은 해당 기기에 저장됩니다. 민감한 업무자료는 실습에 입력하지 마세요.
- 사이트 및 DOCX의 실측 전후 사례, 파일럿 수치는 사실로 대체하지 않았습니다.
- `index.html`에서 실습 카드 생성/다운로드, 과정 선택, 계산기 동작을 브라우저에서 확인했습니다(로컬 테스트).
