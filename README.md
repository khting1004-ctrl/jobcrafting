# 꿈쓰는회사 × 권글 — 기업교육 연구개발 허브 V11

배포일: 2026-11-11 · 기존 V10 전체 유지 + 연구개발 기능 추가

## 주요 변화
- `lab.html`: 강의 연구과제 / 사례 노트 / 파일럿 로그 / 개선 이력을 실제로 작성·편집·검색·백업하는 작업실
- `sources.html`: 공식 원문 9건과 연구별 근거·해석 한계·강의 활용 구분, 필터·검색
- `protocol.html`: 시간별 연구/평가 프로토콜, 자체 루브릭, 기업 담당자 인터뷰 질문 12개
- 기존 7페이지: 상단 메뉴에서 새 연구개발실 접근 가능, 메인에 연구개발 안내 추가
- `assets/research-v11.css`, `assets/research-lab.js`, `assets/research-sources.js`, `assets/v11-evidence.json` 신규

## 운영 및 데이터 제약
- 새 연구개발실은 브라우저 `localStorage`만 사용합니다. **로그인·서버 저장·동기화·다른 기기와 공동 편집은 구현하지 않았습니다.**
- 자동 저장 및 JSON 내보내기/가져오기 기능이 있으며, 다른 기기에서 사용하려면 JSON 백업을 직접 옮겨야 합니다.
- 백업에는 자유기록 원문이 포함되므로 기업기밀, 개인정보를 입력하지 말고 저장 파일을 보호하세요.
- 자료은행의 연구 9건은 자료 출처와 적용 한계를 요약한 것으로 실제 강의·AI 활용 효과를 보증하지 않습니다.
- 기존 V8/V9 실습·제출·강사용 CSV 가져오기 기능과 localStorage 키, Netlify Forms 양식명을 수정하지 않았습니다.
- 파일럿 비교는 실측·품질·비교 조건을 확인한 경우에만 관찰 차이를 표시합니다. 관찰 차이는 인과효과가 아닙니다.
- 강사용 dashboard는 기존처럼 CSV/JSON 수동 가져오기 방식이고 인증/서버 데이터 연동은 없습니다.

## 실제 운영 순서
1. `lab.html`에서 강의 연구과제 생성
2. `sources.html`에서 근거 확인 후 출처 ID 연결
3. `protocol.html`에 따라 인터뷰 및 파일럿 프로토콜 작성
4. `practice.html`에서 실습, `checkin.html`에서 교육 전후 추적
5. `dashboard.html`에서 수동 파일 분석, 결과를 `lab.html` 파일럿에 요약 기록
6. 개선 이력을 남기고 JSON 백업

## 배포
- ZIP 최상위 `index.html` 포함. Netlify Sites > Deploys 에 ZIP 전체 업로드.
- 이전 버전 보존 시 별도 테스트 사이트에 먼저 배포.
- 공개 배포는 누구나 `lab.html`에 접속할 수 있지만 **기존 기록을 공유하지 않습니다**. 개인 브라우저 로컬 기록에 불과합니다.
- 공동 편집, 접근 제어, 중앙 DB가 필요할 경우 별도 인증·백엔드 개발이 필요합니다.
